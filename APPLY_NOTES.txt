SCHOOLS SOLUTIONS HUB PAKISTAN — Backend & System Integration Foundation

GitHub write access is currently blocked by the connected GitHub integration (the
repository is readable, but write operations return HTTP 403). This bundle contains
the exact implementation prepared for the repository.

Apply:
1. Add the complete `backend/` directory from this bundle.
2. Replace root `script.js` with the bundled `script.js`.

No existing HTML/CSS is intentionally changed.

After deployment:
- Run `cd backend && npm test`
- Run `npm start`
- Serve the front end from the same origin as the API, or set
  `window.SSHP_API_BASE` to the deployed API base URL before script.js loads.

The backend intentionally does not claim authentication, payments, admin workflows,
notifications, or managed database infrastructure as complete. Those remain later
integration layers.
